# Prakhar Pandey — Personal Portfolio

Welcome to the repository for my personal portfolio website! This site showcases my projects, skills, experience, and achievements as a Computer Science student passionate about software development, data analytics, and machine learning.

## 🚀 Live Demo

You can view the live website here: [Prakhar Pandey Portfolio](https://prakhar1-8.github.io/Portfolio/) *(Note: If you have enabled GitHub Pages, this link will be active!)*

## 🛠️ Technologies Used

*   **HTML5:** Structure and content of the website.
*   **CSS3:** Styling, layout, animations, and responsive design.
*   **JavaScript:** Interactivity, typing effects, and dynamic behaviors.

## 📂 Sections Included

1.  **About Me:** A brief introduction to my background and interests in tech.
2.  **Projects:** Highlights of my recent work, including:
    *   AI Voice Assistant
    *   Weather App
    *   House Price Prediction Model
    *   Personal Portfolio Website
3.  **Experience:** Details on my software development internships, trainings, and leadership roles (like Technical Head for E-Cell).
4.  **Achievements:** Extracurricular successes, hackathon organization (UHack, Enigma), and sports achievements.
5.  **Gallery & Contact:** Event photos and how to get in touch with me.

## 💻 How to Run Locally

1.  Clone this repository:
    ```bash
    git clone https://github.com/Prakhar1-8/Portfolio.git
    ```
2.  Navigate to the project directory:
    ```bash
    cd Portfolio
    ```
3.  Open the `index.html` file in your favorite web browser.
